# Quantum-Analytics-Finance-Data-Analysis-Projects

A collection of finance-focused data analytics projects done with Quantum Analytics, covering investment behaviour and global debt trends. Built with Excel and Power BI to turn financial data into clear, actionable insights.

---

## 📁 Projects in This Repository

### 💰 [Investment Preference Excel Project](https://github.com/DataWithMowa/Quantum-Analytics-Finance-Data-Analysis-Projects/tree/main/Investment%20Preference%20Excel%20Project)
An Excel analysis of 40 investors, breaking down investment preferences by gender, age group, and risk tolerance — revealing that Mutual Funds dominate across the board, and that risk matters more to younger investors while returns drive older ones.

### 🌍 [Global Debt Power BI Project](https://github.com/DataWithMowa/Quantum-Analytics-Finance-Data-Analysis-Projects/tree/main/Global%20Debt%20Data%20Power%20BI%20Project)
A Power BI dashboard combining five global debt datasets — Central Government, General Government, Household, Non-Financial Corporate, and Private debt — across 190 countries and seven decades, to see which debt type carries the heaviest load and how it's shifted over time.
